# Ved Patel - Professional Portfolio

![Ved Patel Portfolio](src/assets/ved.png)

A modern, responsive, and interactive personal portfolio website built to showcase my skills, projects, and professional experience. Designed with a focus on clean aesthetics, smooth animations, and a seamless user experience.

## 🚀 Features

- **Modern Tech Stack**: Built with React, TypeScript, and Vite for performance and type safety.
- **Responsive Design**: Fully responsive layout that works perfectly on all devices (Mobile, Tablet, Desktop).
- **Dark/Monochrome Theme**: A sleek, professional black monochrome design system using Tailwind CSS.
- **Smooth Animations**: Engaging entrances and interactions powered by GSAP.
- **Interactive Components**: Dynamic project cards, skill bars, and contact forms.
- **Modular Architecture**: Clean code structure with reusable components and sections.

## 🛠️ Tech Stack

- **Frontend**: [React](https://react.dev/), [TypeScript](https://www.typescriptlang.org/)
- **Build Tool**: [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Animations**: [GSAP (GreenSock)](https://greensock.com/gsap/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Deployment**: [GitHub Pages](https://pages.github.com/)

## 📂 Project Structure

```bash
src/
├── assets/         # Static assets (images, PDFs)
├── components/     # Reusable UI components (Navbar, Footer, etc.)
├── data/           # Content data (resume, projects, skills info)
├── hooks/          # Custom React hooks
├── sections/       # Main page sections (Hero, About, Projects, etc.)
├── styles/         # Global styles and Tailwind configuration
├── types/          # TypeScript type definitions
├── App.tsx         # Main application component
└── main.tsx        # Entry point
```
