FLOATING PARTICLE TYPES (mix all of these on each screen):

Type A — GLOWING ORBS:
  - 8–12 soft circular divs, size: 20–60px, fully rounded
  - Colors: #FF2D78, #BF5FFF, #FFD93D, #00D4FF (pick 2–3 per screen)
  - Opacity: 0.15–0.35 (subtle glow, not distracting)
  - Blur: filter: blur(12px) to blur(24px)
  - GSAP animation:
    gsap.to(orb, {
      y: "random(-40, 40)",
      x: "random(-20, 20)",
      scale: "random(0.8, 1.3)",
      duration: "random(4, 8)",
      repeat: -1,
      yoyo: true,
      ease: "sine.inOut",
      stagger: { each: 0.6, from: "random" }
    })

Type B — FLOATING HEARTS (♥):
  - 10–15 heart SVGs or Unicode ♥, size 10–22px
  - Colors: #FF2D78, #FF0099, #FFD93D
  - Start at bottom of screen, float upward and fade out
  - GSAP:
    gsap.fromTo(heart, 
      { y: "100vh", opacity: 0, scale: 0.5, x: "random(10, 90)vw" },
      { y: "-10vh", opacity: [0, 0.8, 0], scale: "random(0.8, 1.4)",
        duration: "random(5, 9)", repeat: -1, delay: "random(0, 6)",
        ease: "none" }

Type C — SPARKLE STARS (✦ / ✧):

  - Color: #FFD93D, #FFF176, #00D4FF

    repeat -1, stagger random, random positions across screen
  - Some also drift slowly (x ±30, y ±30, duration 6s, yoyo)

  - 30 thin rectangle divs (3×14px), rotated random angles

STYLE RULES:
  1. OUTLINES: All shapes have a 2–3px stroke in a deeper shade of their fill
     (e.g. pink fill → deep rose stroke). Stroke-linecap: round,
     stroke-linejoin: round — NO sharp corners anywhere
  2. PROPORTIONS: Cartoonish — heads 25–30% of total height, large eyes (if any),
     stubby rounded limbs, exaggerated cute features
  3. VOLUME: Every filled shape uses a radial or linear gradient (lighter at top/

  4. SHINE: Every balloon, circle, round object gets a small white oval in the
     top-left quadrant (opacity 0.4–0.6) — classic cartoon highlight
  5. SHADOWS: Soft ellipse below characters/objects (dark color, opacity 0.1,
     blur 4–6px) for grounding — prevents floating-in-space look
  6. EXPRESSIONS: If any character face is shown, use simple dot eyes + curved
     smile. Keep it minimal and cute, not realistic.
  7. COLORS: Use the new palette from Section 1 — no more dull pinks.

SECTION 7 — PERFORMANCE RULES FOR HEAVY ANIMATIONS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Since we are adding many more animations, these rules MUST be followed:

  1. All animated elements: add will-change: transform to their CSS
  2. GSAP animations: always use transform properties (x, y, scale, rotation)
     NOT layout properties (width, height, top, left, margin)
  3. Blurred aurora orbs: use will-change: transform, filter
  4. Cap floating particles per screen: max 50 animated elements total
  5. Shooting stars (Screen 6): use setTimeout to spawn, remove DOM element
     after animation completes (prevents DOM buildup)
  6. GSAP cleanup: every useEffect/useGSAP that creates tweens must return
     a cleanup: gsap.context.revert() or tl.kill()
  7. Backdrop-filter (blur): limit to 3–4 elements per screen on mobile
     (blur is GPU expensive on older phones)
  8. Test on Chrome DevTools → Performance tab: aim for 60fps
     If frame drops, reduce blur radius or particle count first
